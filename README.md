# ISIC 2018 Image Segmentation Research Project

An educational computer-vision project based on Task 1 of the [ISIC 2018 Challenge](https://challenge.isic-archive.com/landing/2018/). The project explores semantic segmentation of dermoscopic skin-lesion images and the practical workflow required to turn labeled images into segmentation masks.

> **Status:** Completed learning project. The repository is no longer under active development and is preserved as an example of early research-oriented computer-vision work.
>
> This project is not a medical diagnostic system and must not be used for clinical decisions.

## What this project demonstrates

- Image and mask preprocessing
- Semantic segmentation problem formulation
- Dataset inspection and experiment setup
- Computer-vision model development
- Evaluation of predicted segmentation masks
- Reproducible research workflow and technical documentation

## Dataset

The project is based on the ISIC 2018 image-segmentation challenge dataset. The dataset is not redistributed here. Obtain it from the official ISIC challenge resources and follow the applicable terms of use.

## Project context

This repository was created as a practice and implementation exercise while learning how to build computer-vision systems for scientific and real-world image data. It complements my later work in applied machine learning, multimodal intelligence, and software for physical systems.

## Limitations

This is an educational project rather than a validated medical system. It has not been developed, tested, or approved for diagnosis, treatment, screening, or clinical deployment.

## Project status

Archived learning experience. The source remains public to document my progression in image segmentation, applied ML experimentation, and research software development.
